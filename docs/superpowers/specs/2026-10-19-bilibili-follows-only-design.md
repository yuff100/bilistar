# 只看关注的 B 站插件

## 意图

B 站首页的推荐太乱，人一刷就会被带进不想看的内容。这个插件给同一个人自己用：人留在 B 站页面上，打开之后只看见已经关注的 UP 主，以及他们的投稿视频。

## 目标

- 以浏览器插件的形式跑在 B 站页面上。
- 使用浏览器里已经登录的 B 站账号。插件不提供用户名密码输入，不保存密码，也不把 Cookie 复制到插件自己的存储里。
- 首页没有 B 站原来的顶栏、搜索和分区入口。左边是关注的 UP 主，右边是投稿视频。
- 右边默认是所有关注的人最近的投稿，新的在前。点左边某个人，右边换成他的全部投稿，新的在前。点「全部更新」回到所有人混在一起的列表。
- 点开一条已关注 UP 的视频：仍用 B 站自己的播放器，评论留着，顶栏拿掉。右侧只放这个 UP 的其他投稿，不放算法推荐，也不放「接下来播放」。
- 打开一条未关注 UP 的视频：页面上只有这条视频和他的关注按钮。
- 「全部更新」和某位 UP 的投稿列表里只有投稿视频。直播和图文动态不出现。
- 收藏、历史记录、稍后再看可以显示。排行榜不显示。已关注 UP 的专栏、合集、课程可以显示。
- 消息、创作中心、账号设置不显示。
- 关掉插件后，B 站恢复原来的样子。

## 非目标

- 第一版不做独立网站，不做手机 App，也不为以后的 App 预留服务端。
- 不做插件内的账号切换、搜索、追番、直播、图文动态、热门、会员购。
- 不重做播放器、弹幕和评论。已关注视频沿用 B 站播放页里的这些部分。

## 反目标

- 插件开着的时候，用户仍能从页面上进入推荐、热门、排行榜或相关推荐。收藏、历史记录、稍后再看里出现未关注 UP 的视频是允许的，不算违反这一点。
- 插件向用户索取或保存 B 站密码。

## 约束

- 只访问当前浏览器里这个用户自己的 B 站登录状态，用来读取他的关注列表和投稿，并执行他自己的关注操作。
- 第一版只支持 Chrome。这是用户的决定。
- 界面文案用简体中文。

## 页面

### 未登录

插件不显示密码框。未登录时不渲染推荐内容，让用户走 B 站自己的登录。登录完成后再进入下面的首页。具体怎么挡住登录页周围的推荐，由实现者决定，只要推荐内容不出现。

### 首页

人在 B 站上，但整页换成插件的布局。

首页为三栏（2026-10-20 增补，用户决定）：左栏关注列表、中栏投稿列表、右栏播放区。左栏和中栏可收起、可恢复；右栏用 B 站内嵌播放器（player.bilibili.com）播放中栏点选的投稿，弹幕正常；内嵌播放器没有评论区，需要评论时从右栏进入完整播放页。

- 左边：标题为关注。第一项是「全部更新」，下面是关注的 UP 主，一人一行，能看出是谁。有新投稿的人排在更上面。这是我的决定。不单独分组「特别关注」，也不把追番放进来。
- 右边：选中「全部更新」时，是所有关注 UP 的投稿，按发布时间从新到旧。选中某个人时，是他的全部投稿，同样从新到旧。专栏、合集、课程不混进这两条时间线。点开这个已关注的人之后，可以再进入他的专栏、合集和课程。这是我的决定：它们可以显示，但不铺在首页的投稿列表里。
- 一条投稿要能看出标题、是谁发的、什么时候发的。点它进入播放页。
- 没有直播卡片，没有图文动态。
- 关注很多、投稿很多时要能继续往下看。每次加载多少条由实现者决定。
- 一个人都没关注，或暂时没有投稿时，页面说明这一点，不拿推荐视频来填。文案由实现者决定。
- 多 P 投稿在列表里算一条。分 P 留在播放器里，不拆成多条。这是我的决定。

### 已关注 UP 的播放页

- 使用 B 站播放页和它的评论。
- 拿掉顶栏，以及首页、番剧、直播、会员购、搜索这些入口。
- 页面上有「返回关注」。点它回到首页的「全部更新」。
- 右侧只列出这个 UP 的其他投稿，从新到旧。点其中一条，仍按已关注的播放页规则打开。
- 播放器下方 B 站原来的标题、点赞、投币、收藏、分享可以留着。这是我的决定。
- 相关推荐、「接下来播放」、播放结束时冒出来的推荐，都不显示，也不自动连播这些推荐。这是我的决定。弹幕保持播放器原样。

### 未关注 UP 的播放页

- 只保留这条视频的播放器，以及这个 UP 的关注按钮。
- 不显示评论、他的其他视频、推荐、顶栏，以及点赞、投币、收藏、分享。
- 关注成功后，这个页面变成「已关注 UP 的播放页」：评论出现，右侧换成他的其他投稿。
- 关注失败时留在这一页，并让用户知道没关注上。失败时的具体文案由实现者决定。

### 其他 B 站地址

插件开着时，下面这些地址都回到首页的「全部更新」，不展示它们原来的内容：

- 搜索
- 直播
- 动态
- 排行榜
- 热门、番剧、影视、游戏、漫画、会员购、赛事等分区
- 消息、创作中心、账号设置。要用这些功能，先关掉插件
- 未关注 UP 的个人空间、专栏、合集、课程。不提供他的投稿或其他作品目录
- 作者不是已关注 UP 的专栏、合集、课程，以及不归属某一位已关注 UP 的合集目录

下面这些可以显示：

- 收藏、历史记录、稍后再看。列表按 B 站原来的内容显示，里面可以有未关注 UP 的视频。点开一条时，仍按作者是否已被关注，使用对应的播放页规则。
- 已关注 UP 的专栏、合集、课程。
- 已关注 UP 的个人空间，按首页里点中这个人来显示：右边是他的全部投稿，并可进入他的专栏、合集和课程。

收藏、历史记录、稍后再看，以及已关注 UP 的专栏、合集、课程这些页，同样拿掉通往推荐、热门、排行榜的顶栏。列表或正文保留。这是我的决定。

短链如果最终打开的是一条视频，就按这条视频的作者是否已被关注，使用对应的播放页规则。这是我的决定。

## 留给实现者

- 插件的目录结构、清单版本，以及用内容脚本改页面还是在页面里换成自己的界面。结果必须是上面这几块页面，人仍在 B 站的站点上。
- 用当前登录态读取关注列表和投稿列表的具体请求。
- 左边名单和右边列表一次取多少、怎么翻页。
- 空状态和关注失败的文案。
- 未登录时挡住推荐的具体做法。
- 插件在浏览器里显示的名字。
